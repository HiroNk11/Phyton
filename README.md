# Ejercicios de Python

Ejercicios de Python sobre archivos CSV, programación orientada a objetos, consultas sobre colecciones y pruebas con unittest. Los ejemplos usan la biblioteca estándar y se ejecutan por separado.

## Estructura

```text
01_fundamentos/
  calculadora_cli.py
  conversor_temperatura.py
02_archivos/
  contactos_csv.py
03_poo/
  banco.py
04_reportes/
  reportes_ventas.py
05_solid/
  notificador_pedidos.py
06_patrones/
  strategy_descuentos.py
  repository_productos.py
07_api_simulada/
  clientes_api.py
08_testing/
  calculadora.py
  test_calculadora.py
scripts/
  run_tests.py
.github/workflows/
  python-tests.yml
```

## Objetivo

Practicar de forma progresiva:

- Sintaxis basica de Python
- Funciones y validaciones
- Manejo de archivos CSV
- Programacion orientada a objetos
- List comprehensions y reportes
- Principios SOLID
- Patrones de diseno
- Simulacion de clientes API
- Pruebas automatizadas con `unittest`
- Integracion continua con GitHub Actions

## Como ejecutar

Desde la raiz del repositorio:

```bash
python 01_fundamentos/calculadora_cli.py
python 04_reportes/reportes_ventas.py
python scripts/run_tests.py
```

## Requisitos

Los ejemplos usan solo la libreria estandar de Python. No hace falta instalar paquetes externos.
